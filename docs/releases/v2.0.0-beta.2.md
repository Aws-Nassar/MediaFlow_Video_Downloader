This beta fixes release CI setup for the current Android SDK packages and introduces native Kotlin Android alongside the Python/PyQt Windows application. Flutter and Chaquopy are no longer required by this version.

### Downloads

- **MediaFlow.exe**: portable Windows application, with FFmpeg, FFprobe, Deno and yt-dlp EJS data bundled.
- **MediaFlow-Android.apk**: installable debug APK for ARM64 phones and x86_64 emulators, Android 7.0 or newer. Production signing and broader real-device coverage remain future work.
- **MediaFlow-Linux**: Linux build produced by the release workflow.
- **SHA256SUMS.txt**: checksums for the downloadable packages.

### Changes

- Native Android UI with dark/light modes, English/Arabic navigation, and RTL support.
- Background Android download queue, share-to-app, private cookie import, Open/Share/Export, and interrupted-job recovery.
- HTTP/HTTPS original-file downloads and dedicated public Drive folder discovery.
- Video/Audio mode can save an available playback stream when a Drive original video download is refused. Original file mode does not silently substitute playback copies.
- Actionable errors, bounded retries, cancellation, safe filenames, atomic history storage, and redacted diagnostics.
- Updated build instructions, ignore rules, automated checks, and native Android release paths.

### Validation

- 12 Python checks and 3 Android unit checks passed; Android lint passed.
- 15 of 18 supplied links passed anonymous metadata or folder-listing checks. These checks do not mean every file was fully downloaded.
- Video and audio were verified in bounded YouTube, Facebook, TikTok and Drive playback samples.
- Android background downloading of a 35-second YouTube Short and SHA-256 verification of a synthetic file passed in an API 34 emulator.
- Native Drive preview, light mode, Arabic navigation and state restoration were verified.

### Known limitations

- The supplied Instagram reels were blocked anonymously; account cookies or rate-limit recovery may be necessary. One supplied Kick VOD returned 404.
- MEGA encrypted shares, WeTransfer share pages, full Dropbox folder traversal and Drive OAuth/shared-drive pagination are not implemented.
- Live cancellation preserves partial files and does not provide a dedicated Stop-and-finalize workflow. Android background time limits still apply.
- The Android package uses debug signing. Export downloads before uninstalling; upgrading an existing installation requires matching signing keys.
- Some technical text remains in English. Windows batch queue UI and desktop in-app engine updates are pending.

The native release is published from `release/native-v2.0.0-beta.1`; newer work on `main` is preserved separately. See `docs/project-review.md` in the source archive for the migration review and remaining work.

The earlier `v2.0.0-beta.1` tag stopped during Android SDK setup and did not produce a GitHub release. This tag includes the SDK setup correction.
