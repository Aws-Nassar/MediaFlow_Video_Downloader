MediaFlow for Windows
=====================

Run mediaflow.exe from this folder.

Keep mediaflow.exe, data\, and tools\ together. The tools folder contains the
yt-dlp and FFmpeg binaries used for downloads.

The build is unsigned, so Windows SmartScreen may show a warning. The app stores
its queue and history in the current user's application-support folder, and its
default downloads go to %USERPROFILE%\Downloads\MediaFlow.

This is an early prerelease. See THIRD_PARTY_NOTICES.md in this folder and the
project repository for the current limitations and third-party license
information.
